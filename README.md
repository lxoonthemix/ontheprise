# ON THE PRISE

Analyseur de prise vocale — **LXO ON THE MIX**

Niveau, bruit de fond, sibilance et placement micro, analysés dans le navigateur.
Aucun fichier n'est envoyé nulle part : tout le calcul se fait sur la machine du visiteur.

## Mettre à jour le site

Remplacer `index.html` par la nouvelle version. GitHub Pages republie tout seul
en une à deux minutes.

## Un seul fichier

Tout est dans `index.html` : styles, scripts, données matériel, traductions FR/EN.
Aucune dépendance, aucun serveur, aucune base de données.
